# 使用指南

## 安裝

建置後的 APK 位於：

```text
app/build/outputs/apk/debug/app-debug.apk
```

可使用 Android Studio 安裝，或透過 ADB：

```powershell
adb install -r "app/build/outputs/apk/debug/app-debug.apk"
```

## 匯入樂譜

1. 開啟 App。
2. 按「示範曲」載入約 40 秒的五聲部原創小品「晨光小遊行」，或按「＋ 匯入樂譜」。
3. 選擇 MusicXML、MXL 或 JSON 包裝檔。
4. 匯入成功後會進入「所有曲目」。
5. 音譜庫會保存 App 私有空間的檔案副本。

### 免費樂譜來源

可從 [AICoevolution Shelf](https://www.aicoevolution.com/shelf) 免費下載 MusicXML 樂譜，再回到 App 使用「＋ 匯入樂譜」開啟。這是外部網站，實際提供內容、下載方式與授權條款以網站標示為準。

## 播放

1. 從首頁進入「所有曲目」或「播放清單」，再點選曲目。
2. 採樣庫與音訊串流準備完成後會自動播放。
3. 「所有曲目」會以目前查詢和排序結果建立佇列；播放清單則依使用者排列的順序播放。
4. 播放器提供上一首、播放／暫停、下一首、隨機播放，以及關閉／清單／單曲三段循環。
5. 點選音符卷軸或拖曳進度列可定位；小節定位位於音符卷軸上方，播放／暫停則位於底部播放控制列。
6. 返回其他頁面、切換到背景或鎖定螢幕時，播放可繼續進行。
7. 各主要頁面底部會顯示迷你播放器；點擊曲目資訊可回到現正播放。

App 被系統完全關閉後，下一次開啟會恢復上次佇列、曲目和進度，但保持暫停。

## 播放清單

- 可新增、改名及刪除播放清單。
- 可一次勾選多首樂曲加入清單。
- 長按清單中的曲目並拖曳，可調整播放順序。
- 移除清單項目不會刪除「所有曲目」中的原始樂譜。
- 可依清單順序播放全部，或直接啟用隨機播放。

## 所有曲目

- 可即時搜尋曲名、作曲者與樂器。
- 可依最近播放、曲名、作曲者、加入日期或長度排序，並切換升冪／降冪。
- 曲目選單可加入播放清單、重新命名或刪除。

## 聲部控制

現正播放頁為每個聲部提供：

- 啟用／停用。
- 旋律樂器替換。
- 發聲狀態與目前樂器顯示。

聲部開關在切換曲目後會恢復為全部啟用；替換樂器會依曲目保存。即時切換不會重設播放進度。

## 播放速度

目前速度選項為 50%、75%、100%、125%、150%，保持音高。速度是全 App 共用設定，切換曲目後仍會沿用。

播放速度是練習倍率，不會改變 WAV 匯出的原始樂譜速度。

## 演奏風格

播放器提供原譜、流行、抒情、自然、浪漫五種風格。風格是全 App 共用設定；切換風格會從目前位置重新準備播放，WAV 匯出與即時播放使用相同風格。

- 原譜：依照樂譜原始力度與時間演奏。
- 流行：節奏較明確，強拍較突出。
- 抒情：音符較連貫，力度較柔和。
- 自然：加入輕微的時間與力度變化。
- 浪漫：延長音符並增加力度起伏。

風格選單會直接顯示這些說明。風格延長的尾音會完整保留；若實際渲染長度因此超過 30 分鐘，App 會拒絕播放或匯出，不會靜默截斷尾音。

## 節拍器與匯出

- 節拍器為四分音符 click，可在播放器開關。
- WAV 匯出使用獨立工作執行緒，不會停止即時播放。
- WAV 為 44.1 kHz、16-bit、立體聲。

## 通知與音訊輸出

Android 13 以上第一次由使用者主動播放時會詢問通知權限。拒絕權限仍可播放。

設定頁最下方會顯示目前音訊輸出、App 版本及 Build 資訊。若 Android 或原生音訊 API 無法提供實際裝置 ID，畫面會顯示「系統推定」或「系統選擇」，不會以已連接裝置猜測實際輸出。

## 顯示模式

右上角齒輪可選擇：

- 系統模式。
- 淺色模式。
- 深色模式。

切換顯示模式不會中斷音訊播放。

## 主題色彩

設定頁提供六個預設主題色彩：元氣粉、莓果紅、珊瑚橘、葡萄紫、晴空藍及薄荷綠。

- 點選色塊會立即套用主題色彩。
- 下方 Hue 彩色滑桿可自訂完整色相範圍。
- 圓形預覽、滑桿、主要按鈕與播放控制會同步更新。
- 主題色彩與深色／淺色模式可分別切換，狀態列和 Navigation Bar 會同步調整圖示明暗。
- 設定頁使用 Android 上一頁按鈕或標題列返回時，都會回到主畫面。
